# Profile assets

Banner and project artwork are custom SVG illustrations for GearJP2. Project graphics are decorative; the bar heights are not experimental measurements.

The toolbox boards embed locally cached SVG icons. Common technology tiles come from [Skill Icons](https://github.com/tandpfun/skill-icons). Additional logos and source URLs are documented in `skills/README.md`. All trademarks belong to their respective owners. Text monograms identify tools without verified logo assets.

The README uses four self-contained `toolbox-*.svg` boards. The individual tiles in `skills/` are retained as editable source assets.
